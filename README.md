# Quiet PayPiggy™ Website MVP

A real Next.js App Router starter for the Quiet PayPiggy™ / Resplendent GirlyPop™ universe.

## Run locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000

## Included

- Premium RGP-inspired home page
- 50-character roster
- Collector Vault
- Universe/Lore page
- Shop concept
- Responsive layout
- No Tailwind dependency; styling lives in `app/globals.css`
